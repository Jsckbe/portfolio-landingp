## Avatar del hero

- En escritorio, el video sigue horizontalmente el puntero.
- En móvil, solo se muestra el video: al terminar, se desvanece brevemente mientras vuelve al primer fotograma, espera cuatro segundos y comienza de nuevo.
- Si el video no está disponible, se muestra la imagen del avatar.

Archivos usados por la página:

- `assets/video/beast-video-hero1.mp4`: animación del avatar.
- `assets/hero2_refurbished.png`: hoja de poses y respaldo del video.
